# ChromaFlow

A browser-based color palette generator built with vanilla JavaScript, HTML, and CSS.

## Features

- Generate complementary, analogous, triadic, and monochrome palettes.
- Lock colors and adjust hue, saturation, and brightness.
- Extract colors from an uploaded image.
- Check color contrast and preview gradients.
- Save favorites, browse palette history, and use undo/redo.
- Copy or export palette values and customize the interface.

## Run locally

Open `index.html` in a modern browser, or serve this folder with any static web server. No package manager or build step is required.

## Technology

HTML5, CSS3, vanilla JavaScript, Canvas, and browser storage for preferences.

## About the suggestions

Palette suggestions are generated locally with color-theory rules. This project does not call an external AI model or service.
